# 기능

관리자가 할 수 있는 일과, 각 기능이 실제로 어떻게 동작하는지 정리한다. 내부 흐름은 [구조.md](구조.md), 테이블은 [DB-스키마.md](DB-스키마.md)에 있다.

| 기능 | 할 수 있는 일 | 화면 | 코드 |

## 2. 기능별 동작

### 수집 소스·발신 그룹
- **소스:** 피드 URL은 중복 등록할 수 없고, 그룹을 하나 이상 골라야 한다. 수집 주기는 60~86400초(기본 300초)다.
- **요청 옵션:** 소스마다 인코딩, User-Agent, 추가 헤더, 타임아웃(1~120초), TLS 최대 버전을 정할 수 있다.
- **목적지 없는 소스:** 그룹에 웹훅이 없어도 저장은 된다. 다만 목적지가 하나도 없으면 수집하지 않는다.
- **그룹 웹훅:**
  - 빈 칸으로 저장하면 기존 값을 유지한다. 지우려면 "연결 해제"를 선택한다.
  - 웹훅 원문은 다시 보여 주지 않는다.
- **목적지·발신 정보:** 여러 그룹이 같은 웹훅과 스레드를 가리키면 하나로 합친다. 발신 이름·아바타는 소스 값이 그룹 값보다 우선한다.
- **지금 수집:** 예약 수집과 같은 경로로 실행하고, 끝날 때까지 기다린다. 이미 수집 중이면 건너뛴다.
- **실패 재시도:** 실패한 작업을 다시 대기 상태로 돌린다. 응답에 나오는 숫자는 대기시킨 작업 수다.

### 템플릿
- **내장 프리셋:** `incident-active` · `news-article` · `link-discussion` · `minimal`. 본문은 직접 고칠 수 없고 복제해서 편집한다.
- **렌더 결과:** 템플릿은 Handlebars로 Discord JSON을 만든다.
  - 쓸 수 있는 값: `item`, `source`
  - 헬퍼: `json`, `truncate`, `stageColor`, `stageLabel`, `eq`
- **검증 시점:** 저장할 때는 길이와 필수 값만 검사한다. Discord 제한(본문 2000자, embed 10개, embed 합계 6000자 등)은 미리보기와 발송 때 검사한다.

### 미리보기와 테스트 발송

| 동작 | 쓰는 항목 | 외부 통신·저장 |
| --- | --- | --- |
| 미리보기(sample) | 소스의 최근 항목. 없으면 합성 샘플 | 없음 |
| 미리보기(live) | 소스 피드를 받아 첫 항목 | 피드 요청만 |
| 테스트 발송 | 최근 항목 또는 합성 샘플 | 첫 목적지 한 곳에 실제 전송. 번역·기록 없음. 같은 목적지에는 5초 간격 |

### 번역
- **상태 확인:** `/model`은 모델 이름, 상태(`ready` · `missing-key` · `invalid-key` · `cooldown`), 키별 상태, 최근 결과와 건수를 보여 준다.
  - 조회만으로는 Gemini를 호출하지 않는다.
  - 토큰 수와 요금은 집계하지 않는다.
- **번역 진단:** 제목(1000자)이나 본문(3500자)을 직접 번역해 본다. `fresh`를 켜면 성공 캐시도 건너뛴다.
- **설정:** 모델과 키는 환경 변수로만 바꾼다. 화면에서는 바꿀 수 없다.

### 발송 검토

| 상태 | 선택 | 결과 |
| --- | --- | --- |
| `held` (대량 신규 보류) | 발송 | 대기 상태로 돌려 워커가 보냄 |
| `held` · `unknown` · `uneditable` | 과거 항목으로 보관 | 작업을 `cancelled`로 보관 |
| `unknown` (결과 불명) | 발송됨 확인 + 메시지 ID | 발송 기록을 등록하고 완료 처리 |

로그를 지워도 발송 판단과 검토 상태는 바뀌지 않는다.

### 로그
- **종류:** 수집(`fetch`), 발송(`delivery`), 번역(`translation`) 세 가지를 한 테이블에 남기고 30일 동안 보존한다.
- **목록 조회:** 최신순으로 기본 100개, 최대 500개씩 읽는다.
- **실시간 수신(SSE):**
  - 접속하면 최근 50건을 먼저 보낸다.
  - 끊겼다가 다시 연결하면 `Last-Event-ID` 다음 기록부터 보낸다.
  - 동시 연결은 5개까지다.

### 설정 이전(Export/Import)
- **내보내기:** 소스·그룹 설정과 템플릿 이름만 담는다. 템플릿 본문, 항목, 발송 이력, 로그, 캐시, API 키, 웹훅 URL, 추가 헤더는 빠진다.
- **가져오기:**
  - 1MiB 이하 파일 하나를 받는다.
  - 먼저 미리보기로 예상 결과를 보여 준다.
  - 기존 설정은 건너뛰기(`skip`)와 덮어쓰기(`overwrite`) 중에서 고른다.
- **새로 들어온 소스는 신규 등록으로 취급한다.** 과거 항목을 다시 보내지 않으며, 웹훅은 다시 입력해야 한다.

## 3. HTTP API

`HX-Request: true`인 요청은 htmx 요청으로 보고 HTML 조각이나 `HX-Redirect`로 답한다. 오류는 `{error:{code,message,fields?}}` JSON으로 답한다(400 검증·보안, 404 없음, 409 충돌, 429 제한, 500 내부 오류).

| 경로 | 메서드 | 응답 |
| --- | --- | --- |
| `/api/sources` | GET · POST | 목록 JSON / 생성 후 행 HTML 또는 이동 |
| `/api/sources/:id` | GET · PATCH · DELETE | 소스 JSON / 수정 후 행 HTML 또는 이동 / 204 |
| `/api/sources/:id/enabled` | PATCH | 행 HTML |
| `/api/sources/:id/poll` | POST | 수집 결과 안내 HTML |
| `/api/sources/:id/test` | POST | 테스트 전송 안내 HTML |
| `/api/sources/:id/retry-failed` | POST | 다시 대기시킨 작업 수 HTML |
| `/api/sources/:id/sample-item` | GET | 항목 또는 샘플 JSON |
| `/api/groups` | GET · POST | 목록 JSON(웹훅 가림) / 행 HTML |
| `/api/groups/:id` | PATCH · DELETE | 행 HTML / 204 |
| `/api/templates` | GET · POST | 목록 JSON / 행 HTML |
| `/api/templates/:id` | GET · PATCH · DELETE | 템플릿 JSON / 행 HTML / 204 |
| `/api/preview` | POST | `{ok, payload}` 또는 단계별 오류(`fetch` · `render` · `validate`) |
| `/api/model/diagnostics` | GET | 모델 상태 JSON |
| `/api/model/diagnose` | POST | 진단 결과 HTML 또는 JSON |
| `/api/delivery-jobs` | GET | 작업 목록 JSON(최대 200개) |
| `/api/delivery-jobs/:id/review` | POST | 처리 후 이동 또는 작업 JSON |

## 4. 보안

- **요청 출처:** 관리 화면과 API는 Host를 검사하고, 변경 요청은 Origin 또는 Referer도 검사한다. 로그인을 대신하는 장치는 아니며 SSH 터널을 전제로 한다.
- **요청 수 제한:** 분당 120회다. 정적 자산, 로그 스트림, 상태 점검은 제외한다.
- **피드 주소:** HTTP·HTTPS만 허용한다. 내부망·loopback·사설 IP는 DNS의 모든 주소와 리다이렉트 대상까지 검사해 막는다.
- **웹훅 주소:** HTTPS의 `discord.com` · `discordapp.com` 웹훅 경로만 허용한다.
- **Discord ID:** 정밀도 손실을 막기 위해 숫자 문자열로 다룬다.

## 5. 알려진 한계

- **요청 전 실패도 `unknown`:** 연결 거부처럼 요청이 아예 나가지 않은 POST도 `unknown`이 된다. `unknown`은 다시 보내는 기능이 없다.
- **검토 알림 없음:** 보류·결과 불명 작업은 알림이 없어 `/delivery-jobs`에 들어가야 보인다.
- **발송 순서:** 날짜가 없는 신규 항목은 피드 순서(보통 최신 글 먼저)대로 보낸다.
- **미리보기 크기 제한:** 실시간 미리보기는 `FEED_MAX_BYTES` 대신 기본 5MiB 제한을 쓴다.
- **잘못된 payload 오류 위치:** `{ "embeds": {} }`처럼 자료형이 틀린 payload는 오류 단계와 위치가 정확히 표시되지 않을 수 있다.
- **Export는 백업이 아니다:** DB 전체 백업이 아니므로 템플릿 본문·웹훅·이력은 복구하지 않는다.
- **이전 DB는 새로 만들어야 한다:** 2026-10-18 스키마 정리 이전에 만든 DB는 새로 만들어야 한다([배포.md](배포.md)).

**제공하지 않는 기능**
- 로그인·다중 사용자·권한
- Gemini 외 번역 공급자, 한국어 외 대상 언어, 화면에서 모델·키 변경
- 번역 토큰·요금 집계
- `unknown` 작업의 재전송
- 다중 프로세스, 외부 작업 큐
